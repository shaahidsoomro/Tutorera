# School subject catalogue rollout

The catalogue uses independent board/qualification/class/subject identifiers with a reference to the existing shared subject. Existing requests and tutor approvals are not rewritten. School preferences do not grant teaching approval; approved subject and level plus the exact preference are required for school-request offers.

The seed is intentionally dry-run by default. From `tutorera-backend`, configure the target MongoDB connection using the normal deployment secrets, then run `npm run build` followed by `npm run academic:seed-school-offerings` and inspect the report. Resolve ambiguous or inactive shared subjects before running `npm run academic:seed-school-offerings -- --apply --confirm=SEED_SCHOOL_OFFERINGS`. It requires MongoDB transactions. Repeated runs preserve existing offering status and reviewer changes. Back up and test in staging first.

The seed contains 1,026 offerings: 957 Pakistani board/class combinations, 44 Cambridge offerings and 25 Pearson offerings. The existing five board-group options are preserved and 25 individual boards are added. Karachi secondary and intermediate boards are limited to SSC and HSSC respectively. These are tutoring catalogue labels, not a statement that every listed subject is a compulsory subject or an official syllabus offered by each board. Board identity and broad education level are supported by the Punjab Higher Education Department (https://hed.punjab.gov.pk/boards), IBCC (https://ibcc.edu.pk/), BSE Karachi (https://www.bsek.edu.pk/) and BIE Karachi (https://biek.edu.pk/). Existing historic free-text requests retain their original matching behaviour. Cambridge IGCSE and Pearson International GCSE use the existing O-Level approval category as an explicitly identified compatibility mapping; distinct qualification IDs still require a separate tutor preference. AS and A offerings likewise use the existing A-Level approval category.

Pearson evidence: https://qualifications.pearson.com/en/qualifications/edexcel-international-gcses.a-z.html and https://qualifications.pearson.com/en/qualifications/edexcel-international-advanced-levels.html. Computer Science IAS/IAL is documented separately at https://qualifications.pearson.com/en/qualifications/edexcel-international-advanced-levels/computer-science-2026.html. No syllabus codes are included.

Before production rollout, complete end-to-end coverage of onboarding, request, matching, acceptance and inactive-offering transitions; review existing eligibility rules for newly introduced subjects. Seed and deployment are separate steps, and neither is performed by this document.
